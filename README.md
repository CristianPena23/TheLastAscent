# TheLastAscent

Videojuego 2D metroidvania de plataformas ambientado en los círculos del infierno de Dante. Desarrollado en Unity como proyecto del diplomado en Desarrollo y Creación de Videojuegos.

## Características
- Exploración y progresión por habilidades en 2D.
- <mecánicas principales: salto, dash, combate...>
- Ambientación sonora diseñada para reforzar la narrativa.
